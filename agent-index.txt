MHA-Roleplay is a roleplay transcript (alternating User and Model turns) split into 23 numbered pages of up to 8000 characters each, in story order. Pages break between turns where possible, so read them in sequence; each is a plain HTML page. The main page lists every page with a short preview of how it opens.
